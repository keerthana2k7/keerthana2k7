## Selected Projects

### Smart Canteen System
Peak-hour college canteen counters suffer from congested physical queues, order mistakes, and manual cash reconciliation bottlenecks.

**What I built:**  
A Java desktop ordering and inventory management system with separate student and administrator interfaces. Built time-slotted meal pre-orders in 30-minute intervals, an order queue using linked-list data structures, digital wallet transactions, and relational MySQL persistence through JDBC for catalog and transaction logging.

**Tech:**  
Java • Java Swing • JDBC • MySQL • Data Structures (OOP)

### RVKS Farm Management System
Family-run poultry farms often struggle with paper-based flock tracking, feed raw-material shortages, manual wage calculations, and poor connectivity in field sheds.

**What I built:**  
A full-stack agricultural operations platform featuring flock mortality auditing with database check constraints, self-formulated feed recipe validation with automatic shortage prevention, daily egg collection logs, worker attendance and payroll, and offline data logging using IndexedDB with PWA background sync.

**Tech:**  
Python (Flask) • SQLite / MySQL • Docker • Docker Compose • PWA • Chart.js

**Repository:**  
https://github.com/keerthana2k7/RVKS_WEB

**Tech:**

**Repository:**  
https://github.com/keerthana2k7/DAS_MAP

### Smart Ventilation IoT System
Poor indoor air quality and hazardous gas accumulation in enclosed spaces require proactive, automated environmental mitigation rather than reactive manual ventilation.

**What I built:**  
An embedded hardware monitoring system pairing an ESP32 microcontroller with an MQ-135 gas sensor to autonomously regulate fan motor states based on configurable threshold limits. Features webhook telemetry ingestion (`POST /api/iot/webhook`), live fan card metrics, and Socket.IO real-time state broadcasts.

**Tech:**  
IoT • ESP32 • Node.js / Express • Socket.IO • Webhooks • MySQL

**Repository:**  
https://github.com/keerthana2k7/smart-ventilation-system
