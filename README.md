## 🚀 Featured Projects

### 1. [Smart Canteen System](https://github.com/keerthana2k7/Smart-Canteen-System)
A Java-based ordering and billing desktop application designed to streamline college canteen operations during peak hours.
- Implemented user and admin authentication, dynamic menu display, order cart handling, and order queue processing.
- Built SQL-backed persistence with JDBC and MySQL for order histories, menu updates, and transaction logging.
- **Tech Stack**: Java, Java Swing, JDBC, MySQL, OOP

### 2. [RVKS Farm Management System](https://github.com/keerthana2k7/RVKS_WEB)
A full-stack agricultural operations platform built for farm and poultry business management.
- Features worker attendance and payroll tracking, feed formulation recipe validation with raw material shortage prevention, daily egg collection logs, and multi-dimensional financial reporting.
- Designed with responsive PWA capabilities using IndexedDB for offline operational logging and background sync.
- **Tech Stack**: Python (Flask), SQLite / MySQL, Docker, Docker Compose, PWA, Chart.js

### 3. [DevTrack — DSA & Full-Stack Roadmap Tracker](https://github.com/keerthana2k7/DAS_MAP)
An interactive learning platform and progress tracker covering 340+ computer science engineering topics across 9 core domains.
- Features dynamic roadmap completion metrics, scientific spaced repetition revision schedules (`1d → 3d → 7d → 14d → 30d`), live study session timers, problem logging with LeetCode/GFG tags, and activity streak heatmaps.
- **Tech Stack**: React 19, TypeScript, Vite, Tailwind CSS, Recharts

### 4. [Smart Ventilation IoT System](https://github.com/keerthana2k7/smart-ventilation-system)
An automated indoor ventilation and air quality monitoring system powered by microcontroller logic and sensor feedback.
- Uses ESP32 hardware integrated with gas and air quality sensors to automate fan motor states based on configurable threshold limits.
- Features webhook-only data ingestion (`POST /api/iot/webhook`) for lightweight, real-time fan status and runtime telemetry.
- **Tech Stack**: IoT, ESP32, Node.js / JavaScript, Webhooks, Sensors

### 5. [MultiDrive — Multi-Service Web Platform](https://github.com/keerthana2k7/mini-hackathon)
A full-stack service platform consolidating food ordering, ride booking, and service requests into a unified portal.
- Implemented user authentication, service booking modules, responsive layouts, and normalized MySQL relational schemas. Shortlisted as a finalist in the college mini-hackathon.
- **Tech Stack**: HTML, CSS, JavaScript, Bootstrap, PHP, MySQL

### 6. AI-Driven Public Health Chatbot
An AI-powered conversational assistant developed for public health awareness and disease information guidance.
- Incorporates natural language processing and intent classification pipelines with open-source Meta LLaMA models for accessible real-time query support.
- **Tech Stack**: Python, NLP, Meta LLaMA, HuggingFace Transformers, PyTorch
